# WeatherV1 — דף הסבר (Cheat Sheet)

> מסמך הסבר קצר לפגישה. טכני אך נגיש. מסביר מה האפליקציה עושה, איך זורם המידע, ואיך זה בנוי.

---

## בשורה אחת

**WeatherV1 הופכת הקלטת קריינות (אודיו) לסרטון תחזית מזג אוויר אנכי (9:16) מוכן לרשתות — אוטומטית.**
המשתמש מקליט/מעלה קריינות, והאפליקציה מתמללת, מתכננת סצנות, בוחרת קליפים מתוך קטלוג מקומי, ומרכיבה וידאו עם ffmpeg.

---

## הזרימה (The Flow) — 5 שלבים

```
  אודיו MP3
     │
     ▼
1.  תמלול  ──────────►  OpenAI Whisper (ענן)         "מה נאמר ובאיזה תזמון"
     │
     ▼
2.  תכנון סצנות  ────►  LLM (Claude או GPT)            "לכל קטע טקסט — איזו סצנה צריך"
     │
     ▼
3.  בחירת קליפים  ───►  קטלוג מקומי (Picker)          "התאמת כל סצנה לקליפ קיים"
     │
     ▼
4.  ולידציה  ────────►  בדיקת טיימליין שלם             "כיסוי מלא, ללא חורים"
     │
     ▼
5.  רינדור  ─────────►  ffmpeg → MP4 אנכי 9:16        הסרטון הסופי
```

**נקודה חשובה:** רק התמלול דורש ענן (Whisper). שלב ה-LLM ניתן להחלפה — Claude או GPT, לפי בחירת המשתמש בהגדרות. הרינדור והקטלוג **מקומיים לחלוטין**.

---

## איך זה בנוי (Architecture)

- **אפליקציית Next.js אחת** (Next 16 + React 19) שרצה בשתי סביבות:
  - **Web / Server** — שרת Node ארוך-טווח עם ffmpeg מקומי (לפריסה בענן/דאטה-סנטר).
  - **Desktop** — אפליקציית Electron שעוטפת שרת Next מקומי (פורט `127.0.0.1:3765`), עם ffmpeg מובנה ואימות session-token פר-הרצה. מיועד למשתמש לא-טכני: התקנה, מפתח API, ולעבוד.
- רוב הקוד זהה בשתי הסביבות; זיהוי הסביבה נעשה אוטומטית.
- העיקרון המנחה: **local-first** — המדיה והעיבוד יושבים מקומית; הענן הוא תוספת אופציונלית.

---

## אחסון ומדיה

- **קטלוג מקומי** — מאגר הקליפים, פוסטרים וקריינויות שמתוכו האפליקציה בוחרת.
- **R2 (Cloudflare) — סנכרון אופציונלי בצד (sidecar):** גיבוי/שיתוף של הקטלוג והמדיה בלבד.
  - הסרטונים המוגמרים **לא** עולים לענן — נשארים מקומית.
  - האפליקציה מדברת עם Worker gateway ב-HTTP (ללא מפתחות קבועים על הדיסק).

## תוצר סופי

- קובץ **MP4 אנכי 9:16** (מותאם רילס/שורטס/טיקטוק).
- נבנה מקריינות קיימת + קטלוג קיים — בלי צילום חדש.

## נקודות שכדאי להדגיש בפגישה

1. **מהיר ואוטומטי** — מקריינות לסרטון מוכן בלי עורך וידאו ידני.
2. **גמיש בספק ה-AI** — לא נעולים על ספק אחד; Claude/GPT להחלפה.
3. **Local-first** — המדיה הרגישה והעיבוד נשארים מקומית; ענן רק אם רוצים.
4. **שתי סביבות מאותו קוד** — דסקטופ למשתמש קצה, שרת לפריסה רחבה.
5. **שקיפות עלויות** — כל job יודע כמה עלה.
