שלב 0

קריינות נכנסת, סרטון תחזית יוצא.

מקליטים את התחזית, והאפליקציה מתמללת, מתכננת סצנות, בוחרת קליפים מהספרייה של V1 ומרכיבה סרטון אנכי מוכן לרשתות. הכל בתוך דפדפן, בלי התקנה.

איך זה עובד

חמישה שלבים, דקות ספורות.

כל שלב רץ במקום אחר. שני שלבים משתמשים בבינה מלאכותית, והשאר הם עבודת וידאו שהדפדפן עושה בעצמו.

מי עושה מה

שלוש בינות מלאכותיות, שלושה תפקידים.

כדאי להכיר אותן, כי כל אחת עונה על שאלה אחרת כשמשהו לא עובד.

ה-Claude שלך (העוזר)

זה שמתקין עכשיו. הוא מסדר תיקיות, יוצר קיצור דרך ומסביר כל שלב. אחרי ההתקנה אפשר לשאול אותו כל שאלה על האפליקציה.

Claude בתוך האפליקציה (המתכנן)

מקבל את טקסט התחזית, מחלק אותו לסצנות ובוחר לכל סצנה קליפ מתאים מהקטלוג. עובד עם מפתח API שלך, ומשלמים לפי שימוש: בערך כמה סנטים לתחזית (הערכה).

Whisper עברית (האוזניים)

מודל של ivrit.ai שמבין עברית ומתמלל את הקריינות עם תזמונים. רץ על המחשב שלך, בתוך הדפדפן. בלי מפתח ובלי עלות. יורד פעם אחת, בערך 760MB.

פרטיות

הווידאו והקול לא יוצאים מהמחשב.

רק טקסט התמלול נשלח ל-Claude כדי לתכנן את הסצנות. הקליפים, הקריינות והסרטון המוכן נשארים בתיקייה שלך.

שלב 1

הספרייה: התיקייה weather.

בר שלח חמישה קבצי zip של הקטלוג. כולם נפתחים לאותה תיקייה, ובסוף יש תיקייה אחת בשם weather.

שלב 2

האפליקציה היא קובץ אחד.

WeatherV1.html נפתח ב-Chrome או ב-Edge. אין התקנה ואין מה להסיר: מעדכנים בהחלפת הקובץ. ה-Claude שלך ישים אותו בתיקייה קבועה ויצור קיצור דרך בשולחן העבודה.

פותחים

לחיצה כפולה על קיצור הדרך מחולל תחזית V1.

בוחרים תיקייה

בפעם הראשונה: בחירת תיקייה ← weather ← אפשר. בפעמים הבאות: לחיצה על המשך.

הדפדפן שואל

Chrome מבקש אישור לערוך את התיקייה. זה כדי לשמור את התחזיות ב-outputs.

שלב 3

מפתח Claude, פעם אחת.

המפתח הוא שלך ונשאר רק בדפדפן שלך. ה-Claude שמתקין לא צריך לראות אותו: אתה מדביק אותו בעצמך.

  1. נכנסים ל-console.anthropic.com ← API Keys ← Create Key.
  2. מעתיקים את המפתח (מתחיל ב-sk-ant-).
  3. באפליקציה: הגדרות ← מפתח Claude ← מדביקים ← שמירה.
  4. בחשבון Anthropic מוסיפים קרדיט קטן (Billing). תחזית עולה כמה סנטים.
שלב 4

מודל העברית יורד פעם אחת.

בהגדרות, בכרטיס תמלול בעברית, לוחצים הורדת המודל. בערך 760MB, נשמרים בתוך weather/.weatherv1/models. אחרי זה התמלול עובד גם בלי אינטרנט.

שלב 5

תחזית ראשונה.

  1. בלשונית סטודיו: בחר קובץ ← קובץ קריינות.
  2. בודקים את התמלול ומתקנים מילה אם צריך ← המשך לציר הזמן.
  3. Claude מתכנן סצנות ובוחר קליפים. אפשר להחליף קליף בלחיצה.
  4. רינדור ← הסרטון נשמר ב-weather/outputs ומוצג באפליקציה.

הרינדור הראשון לוקח כמה דקות. משאירים את הלשונית פתוחה עד שמופיע הסרטון.
